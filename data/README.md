# Dataset

This folder contains the AI4I 2020 Predictive Maintenance Dataset.

Source: UCI Machine Learning Repository  
Dataset page: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

The dataset is synthetic and was created to represent predictive-maintenance scenarios. The CSV file is kept locally for project analysis and is not committed to GitHub unless its redistribution terms and repository requirements have been checked.
